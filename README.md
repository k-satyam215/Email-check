# Email / SMS Spam Classifier 📧🚫

Email / SMS Spam Classifier is a **machine learning–based text classification application** built using **Python, NLP techniques, and Streamlit**.  
It classifies a given message as **Spam** or **Not Spam** using a **trained ML model and TF-IDF vectorization**.

This project demonstrates a complete **NLP pipeline** from text preprocessing to model inference and deployment.

---

## 🎯 Objective

The goal of this project is to:
- Detect spam messages using Natural Language Processing
- Apply text preprocessing and feature extraction
- Deploy a trained ML model as a web application
- Provide a simple and interactive UI for prediction

---

## 🚀 Key Features

### 🧠 NLP-Based Text Processing
- Lowercasing
- Tokenization
- Stopword removal
- Punctuation removal
- Stemming using **Porter Stemmer**

---

### 📊 Machine Learning Classification
- Uses **TF-IDF Vectorizer** for feature extraction
- Pre-trained ML classification model
- Fast and deterministic predictions

---

### 🖥️ Streamlit Web Interface
- Simple text input for messages
- One-click spam prediction
- Clear classification result display

---

## 🧠 How It Works

1. User enters an email or SMS message
2. Text is preprocessed:
   - Tokenized
   - Cleaned
   - Stemmed
3. Processed text is converted into TF-IDF features
4. ML model predicts spam or not spam
5. Result is displayed to the user
